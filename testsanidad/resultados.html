¿Cómo funciona?

Guía rápida del sistema de resultados

📊
¿Qué se guarda aquí?
Solo los Simulacros Mixtos en modo Examen. El resto de modos y bloques no generan historial en esta página.
💾
¿Dónde se guardan?
En este navegador automáticamente. Si limpias el historial del navegador o cambias de dispositivo, usa el botón guardar para hacer una copia.
📂
Cargar resultados
Si tienes un archivo mis_resultados_osakidetza.json de otro dispositivo, cárgalo aquí. Se fusionará sin duplicar nada.
💾
Guardar resultados
Descarga tu historial completo. Guarda siempre el mismo archivo y sobreescríbelo para no acumular copias.
🗑
Borrar todo
Elimina el historial permanentemente de este dispositivo. Haz una copia antes si no quieres perder los datos.
